# Financial Blind-Spot Detector & Personalised Learning Path Agent

An intelligent agent designed to identify financial blind spots, uncover knowledge or decision-making gaps, and generate personalised, actionable learning paths to foster financial literacy and confidence.

---

## 🎯 Overview

Many people make financial decisions with hidden blind spots—ranging from unnoticed fee structures and tax inefficiencies to risk concentration and behavioural biases. 

This project aims to build an AI-driven agent that:
1. **Detects Financial Blind Spots**: Analyzes financial habits, profiles, and scenarios to pinpoint overlooked risks, misconceptions, and areas for improvement.
2. **Generates Personalised Learning Paths**: Dynamically crafts tailored educational journeys and modular learning recommendations to bridge identified gaps.
3. **Supports Progressive Growth**: Guides users step-by-step through interactive recommendations and actionable financial milestones.
