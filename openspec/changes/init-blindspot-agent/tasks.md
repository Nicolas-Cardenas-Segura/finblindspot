Conventions: every path is relative to the repo root; signatures are the ones defined in `design.md` -> "Shared Types & Interfaces" and must be used verbatim; `npm test` runs Vitest; `npm run typecheck` runs `tsc --noEmit`. Each task depends only on the tasks before it; tasks marked "Spike" need a real credential and may be skipped until it is available without blocking the tasks that follow, except where noted. Tests use fixture profiles from `tests/fixtures/profiles.ts` (task 3.3).
