# Tasks

Conventions: every path is relative to the repo root; signatures are the ones defined in `design.md` -> "Shared Types & Interfaces" and must be used verbatim; field IDs, rule numbers, formulas and copy come from `finance-blind-spot-v1-spec.html` (`v1 §n`); `npm test` runs Vitest; `npm run typecheck` runs `tsc --noEmit`. Each task depends only on the tasks before it; tasks marked "Spike" need a real credential and may be skipped until it is available without blocking the tasks that follow, except where noted. Engine tests use the fixture answer sets from `tests/fixtures/cases.ts` (task 3.4).
